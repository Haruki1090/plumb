# ブランチを締める

**型の終わりは、必ずここを通る。**

作り終えたことと、作ったものが行き先を持つことは別。**ここで決めるのは行き先だけ**で、
何を作るかはもう決まっている。だから `plumb:decision-brief` は出さない——
選び方で作るものが変わらない分岐に、比較の盤面は要らない。

出すと決まった先は `playbooks/opening-a-pr.md`。**隔離を畳む規律は
`playbooks/worktree-cleanup.md` が正本**で、ここには書き写さない
（**principle-encode-lessons-in-structure**）。

## 1. 緑を、いま取り直す

**統合しようとしているツリーの上で、検査を通す。**
セッションの前半で通った記録は、その時点のツリーの証拠でしかない
（**principle-gate-claims-on-evidence**）。

赤いなら、そこで止まる。**行き先の話を始めない。**失敗の内容を出して、直しに戻る。

## 2. 戻り先を確かめる

**このブランチがどこから分かれたかを、推測で埋めない。**
計画・会話・upstream のどれかに書いてある。どれにも無いなら**持ち主に訊く**。

    git log --oneline --graph -20
    git rev-parse --abbrev-ref '@{upstream}' 2>/dev/null

既定ブランチの名前を決め打ちにしない。**戻し先を間違えた merge は、戻すほうが高くつく。**

## 3. 三択を出して、待つ

**統合は持ち主の判断。**こちらは選択肢を並べるところまでで止まる。

- **ローカルで戻り先に merge する**
- **push して PR にする**
- **ブランチのまま残す**（持ち主が後で扱う）

**四つ目を勝手に足さない。**とくに「捨てる」は、この並びに入れない
（下の「捨てる要求が来たとき」を見る）。

名前を持たない作業場では、一つ目が消える。**先に名前を与えるか、push のときに与える。**

## 4. 選ばれたものを実行する

**ローカルで merge する**

隔離の外に出てから戻り先を進め、merge し、**merge した結果の上でもう一度検査を通す**。
結合してはじめて出る失敗がある（**principle-sequence-verifiable-units**）。

赤くなったら**そこで停止**。ブランチも作業場も残す。まだ何も外へ出ていないので、
戻す先はいくらでもある。緑なら、作業場を畳んでからブランチの ref を落とす。

**push して PR にする**

push して、`playbooks/opening-a-pr.md` に入る。**作業場は残す。**
指摘への対応はそこでやる。「PR が出たから作業場はゴミ」ではない。

**残す**

ブランチ名と作業場のパスを言って終わる。**何も消さない。**

## 5. 捨てる要求が来たとき

**持ち主が明示的に捨てろと言ったときだけ**この経路がある。

消える対象——ブランチ、その上のコミット、**作業場に残る追跡外・ignore 済みのファイル**——を
一覧にして見せ、**もう一度確認を取ってから**進む。

    git -C <作業場> status --porcelain -uall
    git -C <作業場> status --porcelain --ignored

**`.env`・ローカルの DB・生成前のメモは Git から戻らない。**
「だいたい捨てていいと言われた」で撃たない（**principle-prove-it-works**——
判断材料は持ち主の言葉そのもの）。

**返すもの:** 検査を通した時刻とその結果、戻り先の名前と確かめ方、持ち主が選んだ行き先、
実行した操作、**残したもの**（ブランチ、作業場のパス、PR の URL）。
