# plumb v0.9.2 — the cost segment is legible

`plumb-statusline-cost` only ever emitted a colour when the budget band fired at 50 % or above.
Below that, the whole segment — dollars, yen and the percentage — carried no escape at all and took
the status line's default foreground, which renders dim grey against the bar. The figure meant to
inform the decision to stop a turn was the hardest thing on the line to read. Every part is now
painted bright white, the same base the account segment uses; the 50 / 80 / 100 % band colours are
untouched and still win for the percentage.

## Compatibility

Output text is identical. Only the escape sequences around it changed, so anything reading the
segment as plain text should strip escapes, as it had to already for the coloured bands.

## Verification

Harness check and selftest passed. The two exact-match assertions now carry the escapes, and a new
one pins the under-50 band to white so the segment cannot fall back to the default foreground
unnoticed.
