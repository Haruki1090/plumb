# plumb v0.7.1 — Portable diagnostics and truthful measurement

Codex-only users can run doctor without a Claude installation. Decision briefs no longer require
an external artifact service, and graph execution keeps failed or missing required work visible.

Session auditing now uses nearest-rank percentiles. Empty or unsupported usage fails explicitly;
missing token categories and incomplete display totals remain unavailable. This prevents an
incomplete transcript from appearing cheaper than a fully measured run.

## Compatibility

Installation commands and model placement are unchanged. Set `PLUMB_RUNTIME=codex` for diagnostics
from a plain shell; active Codex threads are detected automatically. The transcript parser still
supports Claude records only. Consumers of audit JSON must accept `null` for unavailable totals.

## Verification

Harness checks, self-tests with negative fixtures, both plugin validators, strict Codex configuration
parsing with an invalid-field control, and active-runtime doctor passed before publication.
Independent review confirmed the display-total fix and graph contract clarification. A verified
different-family judge was unavailable and remains an explicit skip.
