# plumb v0.30.0 - code policy

`plumb-code-policy report` holds a few cheap rules mechanically: no new comments in application
code, no new effect hooks, no new lint suppressions, or any regex a project names. It looks only at
lines the branch adds against its merge base, so existing code is not reported. Start in report
mode; a project decides when to enforce. Run it from a checkout of the trusted base with
`--worktree` so a branch cannot relax its own policy.
