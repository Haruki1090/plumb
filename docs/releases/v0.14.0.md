# plumb v0.14.0 — the project contract and the rework link

plumb now has a defined way for a repository to hand it the facts plumb cannot know, and a first
use of that: a `Fixes-PR:` line a CI can check without trusting the branch it is checking.

## What changed for users

- **`plumb-path project`** prints the repository's contract file for the checkout you are in. It
  ignores `PLUMB_ROOT` and `root =`, a linked worktree answers with its own file, and `--mkdir`
  is an error.
- **`plumb-project`** reads the contract: `plumb-project <key>`, `--json [<key>]`, `--enforce <key>`.
  Four outcomes by exit status and in JSON: absent and set (0), invalid (2), unavailable (3, no
  `tomllib`). A broken file is invalid for every key. A CI uses `--enforce` so an invalid contract
  or a missing parser fails the job instead of enforcing nothing.
- **`plumb-check-fixes`** validates the `Fixes-PR:` line of a pull request body for the authors a
  repository requires. The caller supplies the author, the list and the pull request number; the
  checker reads no policy.
- **`plumb-doctor`** gains a `contract` block.
- **`docs/project-contract.md`** has the schema, the outcomes and two trusted CI wirings, and says
  plainly that reading the policy from the pull request's own head is wrong.
- **`playbooks/opening-a-pr.md`** tells a listed author to write exactly one `Fixes-PR:` line.

## Compatibility

Additive. A repository without a contract behaves as before: every consumer treats a missing file
as "no policy". `plumb-project` needs Python 3.11+ (`tomllib`) to parse; on an older Python it
answers `unavailable` rather than guessing, and `plumb-doctor` skips the block.

## Verification

`scripts/check-harness.sh` and `scripts/selftest.sh` pass. Selftest covers the path kind, every
outcome and type error, the `Fixes-PR:` rules, 5 MB stress bodies under two seconds, the doctor
block, and an integration fixture that runs the base-commit wiring against a base with an invalid
contract, a head that drops the author, and an unavailable parser.
