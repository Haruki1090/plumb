# plumb v0.31.0 - measured numbers, tested premises

Two principles join the index. `principle-explain-the-number` asks seven questions of any number
before it enters a claim, starting with what limits it and how many errors sat behind it.
`principle-attack-the-premise` fires on the second fix that fails at the same gate: stop, write the
assumption as one sentence, and test the assumption instead of a third fix. Several playbooks gained
a few lines each; the changelog lists them.
