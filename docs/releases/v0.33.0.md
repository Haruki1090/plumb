# plumb v0.33.0 - follow the Claude Code adapter

Upstream pstack is unchanged since 0.15.48. This release checks plumb against upstream's Claude Code
adapter (`docs/harness/claude-code.md`) on a running install and fixes where plumb fell short of it.
The changelog lists every change.

**A reproduction runs on the pull request, not on the base.** An isolated worktree starts at the
default branch. `plumb:pr-review` now gives `plumb:pr-repro` the SHA under review, and the agent checks
it out and confirms it before it writes a test. Before this, a repro could pass on the base and refute
a real defect.

**Commands follow `CLAUDE_CONFIG_DIR`.** Session audit, doctor, worktree audit and prompt weight read
Claude Code's directory from it when it is set. plumb's own configuration stays in `~/.claude/plumb`.

**`check-harness` is green on `main` again.** Rule 9 stops treating reserved test domains and bot
co-author identities as private names.

**Playbook steps become todo lines.** The router asks for each step to be copied into the todo list
and kept until it is done or skipped with a reason. Four more writing rules cover documents.

Nothing changes in a repository's contract. `worker.rules.types` stays off unless an install sets it.
