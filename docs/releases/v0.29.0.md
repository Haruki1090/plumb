# plumb v0.29.0 - cockpit mode

Invoke the cockpit skill to coordinate lanes from a shared brief and a local run log.
`plumb-route` resolves a work kind through the configured roles, `plumb-brief` prepares the
worker handoff, and `plumb-lane` records attempts, checks, and route verdicts. Repeated misses can
demote a route across runs of the same repository.

The [role map](../role-map.md#cockpit-routing-and-briefs) has the configuration and brief format.
