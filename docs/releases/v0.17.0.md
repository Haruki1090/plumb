# plumb v0.17.0 — plumb in a cloud session

A cloud session can now start with plumb installed and configured, and its cost records leave
before its container is reclaimed.

## What changed for users

- **`docs/cloud-setup.md`** has the setup script's lines and the facts of a cloud container behind
  them.
- **`plumb-bootstrap`** writes plumb's config from the setup script's arguments, in a block it owns,
  and reports what is missing (the judge's login, the store's access) without failing the
  environment.
- **`ledger.export = on-stop`** sends each session's records at the end of every turn, in the
  background.

## Compatibility

Additive. `ledger.export` defaults to `manual`, today's behaviour. `plumb-bootstrap` changes only
its own block of the config file.

## Verification

`scripts/check-harness.sh` and `scripts/selftest.sh` pass, including the bootstrap and export-on-stop
cases. The install lines were run in an empty home directory in a cloud container (plumb 0.16.0
installed in about 2 seconds).
