# plumb v0.9.1 — prompt-weight sees the project

`plumb-prompt-weight` counted the global fixed prompt and missed the project's own: skills under
`<project>/.claude/skills/` and the SessionStart hooks in the project's `settings.json` and
`settings.local.json`. A repository that carries a project-level copy of a plugin — 14 skills and a
5.4KB session-start injection, in the case that surfaced this — showed a 23KB global listing while
its sessions still opened at 57KB. Both are now rows in the table, with the same rule: descriptions
only, hooks never executed, nothing printed.

## Compatibility

Additive rows in the text and JSON output; no flag or threshold changes.

## Verification

Harness check and selftest passed, including a project-level skill and hook fixture asserting the
new rows and that neither the hook nor the skill body reaches the output.
