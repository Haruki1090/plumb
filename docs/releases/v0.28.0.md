# plumb v0.28.0 - ledger: OpenCode databases of other accounts

An OpenCode run under another account (`XDG_DATA_HOME=~/.claude-accounts/opencode/<id>`) writes its own
database, `~/.claude-accounts/opencode/<id>/opencode/opencode.db`. `plumb-ledger capture --sweep` read
only the default database, so the usage of those accounts never reached the ledger.

## What changed for users

- `capture --sweep` now reads, besides the default OpenCode database, every
  `<accounts root>/opencode/*/opencode/opencode.db` that exists, in name order. The accounts root is
  `CLAUDE_ACCOUNTS_HOME` when it is set, else `~/.claude-accounts`. A database reachable by two paths
  (a symlink) is read once.
- Each database has its own watermark (the state file was already named by the database's path), so a
  second sweep captures nothing twice and one account's progress does not move another's.
- Only the default database being absent is reported as `missing=opencode.db`; the other accounts'
  databases are listed only when they exist.
- A database that cannot be opened or lacks the tables no longer stops the others. Every database is
  swept, the rows and watermarks of the readable ones are kept (before or after the broken one), and
  the sweep then fails as before: one stderr line, one `capture.log` line, exit status 1. With several
  broken databases the failure reported is the first.
- What is read is unchanged: the same columns of `session_v2` and `session_message`, read-only
  (`mode=ro`, `query_only`), and no account or credential table is queried.

## Do you need to do anything

No. With no other account's database nothing changes. If the accounts live elsewhere than
`~/.claude-accounts`, set `CLAUDE_ACCOUNTS_HOME` to their root.

## Verification

- `python3 scripts/test-ledger-cost.py`: two or three databases captured in one sweep with separate state
  files, a second sweep taking nothing twice, a new row in only one account's database captured alone, a
  symlink to the default database not read twice, no accounts directory giving the earlier result (also
  through the `~/.claude-accounts` fallback), a missing default with a present account database, and a
  broken database, default or another account's, failing the sweep once while the others are captured.
- `bash scripts/selftest.sh`.
- `bash scripts/check-harness.sh`: the versions and this note agree; the remaining NG lines are the
  proper-noun check on addresses in existing test files, as before this release.
