# plumb v0.21.1 - ledger: prices for Opus 4.8 and gpt-6.1-sol

Rows of two models had an unknown cost in `report` and `views`: `claude-opus-4-8` (older Claude Code
sessions) and `gpt-6.1-sol` (Codex rows, captured since 0.21.0).

## What changed for users

- `claude-opus-4-8` is priced from the Claude API pricing page: $5 input, $6.25 5-minute and $10
  1-hour cache writes, $0.50 cache hits, $25 output per million tokens. The writes are the version's
  1.25x and 2x multipliers.
- `gpt-6.1-sol` is priced at the OpenAI API's standard tier, as OpenAI's model and pricing pages state
  it: $2 input, $0.10 cached input, $2.50 cache write (1.25x input), $10 output per million tokens.
  Above 272K input tokens the whole request is billed at 2x input and cache and 1.5x output, which
  is its `long_context` tier. Batch, Flex, fast and ultrafast tiers are not modelled. A Codex session
  on a subscription is not billed per token; the cost compares work, as on a flat-rate Claude plan.
- Each carries its own `checked` and `source`. Both were added to the existing version: neither price
  changed during it, so no priced row changes; only unknown costs become known.

## Verification

`scripts/test-ledger-cost.py` checks the listed rates and prices a Codex row below and above the
272K threshold and an Opus 4.8 row with a 1-hour cache write.
