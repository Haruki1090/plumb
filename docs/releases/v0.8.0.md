# plumb v0.8.0 — Measured efficiency and quality gate

Usage accounting for Codex transcripts is now normalized: cumulative snapshots are deduplicated,
cache-read tokens are never double-counted, and counter resets or unknown formats fail explicitly
instead of silently under-reporting. A new scoped audit mode never scans transcripts outside the
requested location.

bench-score gains an explicit baseline/candidate acceptance gate. A candidate configuration that
saves tokens but regresses precision, recall, or F1 — overall or in any single grade — is rejected.
Only a candidate that holds quality and measurably improves token cost passes. Negative-control
tests prove a cheap-but-worse candidate and an incomplete run cannot pass.

## Compatibility

No changes to installation commands or model placement. Existing Claude audit records and consumers
of bench-score JSON output are unaffected; the new gate fields are additive.

## Verification

Full harness selftest (67 checks, including the new efficiency regression suite) passed before
publication.
