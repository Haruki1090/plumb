# plumb v0.17.1 — keeping a cached cloud environment current

`docs/cloud-setup.md` said the setup script installs the current version in every session. An
environment that caches its container after the setup script keeps the version installed then, and
later sessions skip the script.

## What changed for users

- **docs/cloud-setup.md** records the cache as a fact of a cloud container and adds "Keep a cached
  environment current": update the marketplace and the plugin at session start, then
  `/reload-plugins`.

## Compatibility

Documentation only. No behavior, config key or command changed.

## Verification

Harness check and selftest passed.
