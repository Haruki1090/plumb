# plumb v0.13.1 — how to stay current

The README said how to install plumb but not how to keep it up to date. Claude Code leaves
auto-update off for third-party marketplaces, so an install stayed on its first version unless the
user knew where to look.

## What changed for users

- **README → Install → Updating** explains how to turn on auto-update for the `plumb` marketplace
  in Claude Code, and gives the manual update commands for Claude Code and Codex.
- **Codex sidecar users** are told to re-run `$plumb:setup` after an update, so the copied profile
  and `plumb-*` agents match the installed version.

## Compatibility

Documentation only. No behavior, config key or command changed.

## Verification

Harness check and selftest passed, and `claude plugin validate` accepts both Claude manifests. The
Claude Code steps were checked against the plugin install and loading docs on code.claude.com.
