# plumb v0.25.0 - ledger: a watch that survives its directory, and Codex subagents are recorded

Two gaps in what `plumb-ledger` records, both silent.

## What changed for users

- `plumb-ledger watch` is started by a session-start hook in that session's directory. When that
  directory was removed later (a worktree), every sweep failed to start its child process, for as long
  as the watch lived, and `capture.log` said only `sweep failed: ... exited without an answer`. `watch`
  now changes into the ledger directory at once. `run` and `watch` start the sweep in the ledger
  directory when the caller's directory is gone, and a child that cannot start is logged as
  `did not run: <error type>`.
- A Codex thread spawned by another thread writes its own rollout: its `session_meta`, then its
  parent's. The second header made the normalizer refuse the whole file ("multiple native sessions in
  one transcript"), so no subagent usage was recorded. The parent's header is now accepted when the
  first header names it (`forked_from_id`, `parent_thread_id`); the rows are `role = subagent`,
  `agent_type` = Codex's `agent_role`, `session` and `agent_id` = the thread's own id. A second header
  of any other thread is refused as before.
- A refused rollout is read again once by a plumb version other than the one that refused it, so the
  files refused so far are picked up by the first sweep after the upgrade.
- `state/last-sweep.json` records the time and the failures of the last sweep by `run` or `watch`.
  `plumb-doctor` reads it: NG while the last sweep failed, and a count of refused Codex rollouts.

- `plumb-ledger views` writes "Where the cost was spent" into its README: the period's cost on pull
  request branches, on base branches, on other branches, ambiguous and unknown, each with its share. A
  base branch is one named with the new `--base-branch NAME` (repeatable), or, with `--prs`, a branch
  the pull requests target. `plumb-ledger prs` now keeps `merged_at`, and with such a file the README
  gives the whole period's cost divided by the pull requests merged in it. The cost of a pull
  request's branch falls when work moves to the base branch (a coordinator, a session that opens
  several pull requests); these two figures do not, and `plumb:retro` reads them first.

## What did not change

A snapshot whose `last_token_usage` has a `total_tokens` that is not input plus output is still
refused ("native total tokens disagree"): those tokens are not classified, and dropping them silently
is what `test_native_unclassified_total_is_not_silently_lost` forbids.

## Do you need to do anything

A running `watch` of 0.24.0 is replaced by the next session start. Rollouts that Codex has already
deleted cannot be recovered. To see base branches in the daily views of the store, move the workflow's
pin to this version and add `--base-branch <name>` for each.

- `python3 scripts/test-ledger-views.py`: one new case (base branches named, read from `--prs`, the
