# plumb v0.7.0 — Codex sidecar

plumb can now run from Codex without replacing or weakening its Claude Code setup. Claude remains the
canonical harness; Codex loads a thin adapter over the same playbooks, principles, review standards, and
visible-skip discipline.

## Highlights

- Start Codex with a `gpt-5.6-sol` high-reasoning main thread.
- Use `gpt-5.6-luna` at low or medium effort for exploration and bounded fan-out.
- Spend Luna `max` only on bounded adversarial judgment and finding refutation.
- Use ten native custom agents, including all six axes of `plumb:pr-review`.
- Install either a reusable user profile or project-local `.codex/` configuration.
- Keep the Claude plugin, agents, configuration, and normal installation path intact.

## Install

Install directly from the GitHub-backed Codex marketplace; no clone or local path is required:

```bash
codex plugin marketplace add Haruki1090/plumb
codex plugin add plumb@plumb
```

Start an ordinary new Codex session and invoke `$plumb:plumb-codex`.

The profile and native custom agents are optional. To add them without locating the plugin cache or a
local checkout, invoke `$plumb:setup` and ask for user-scoped setup. For installation into one trusted
repository instead, invoke `$plumb:setup` and ask for project-scoped setup.

Setup will not overwrite a differing profile or agent file unless replacement is explicitly approved.
After user-scoped setup, start the configured session with `codex --profile plumb`.

## Model-family boundary

Sol and Luna are both GPT-5.6 models. Their separation gives plumb a useful division of labor, but it is
not cross-family review. When `role.judge` does not point at a genuinely different model family, plumb
retains the judge todo as an explicit skip instead of claiming that the requirement ran.

## Verification

This release was checked with the repository harness and self-test, the Codex plugin and skill
validators, Codex strict configuration parsing, and the local model catalog. The profile and custom
agents were exercised through both temporary user-level and project-level installations.

## Upgrade notes

There is no Claude migration. Existing Claude users can continue using the same marketplace and
configuration. Codex users should reinstall the plugin after upgrading and rerun
`plumb-codex-install --user --force` only when they intend to replace older agent files managed by plumb.
